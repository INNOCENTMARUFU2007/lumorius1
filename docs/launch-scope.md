# Launch scope
Business Twin is removed from the launch offering: navigation/search and billing remove it, its page redirects to Workflows and backend entitlements deny access on every plan. Existing stored data and implementation files are retained for recovery.
Financial Analyst and Sales Development are removed from the agent catalog and cannot run even through rollout environment overrides. Existing run records are retained. Chief of Staff, Integration Engineer and Operations Manager remain; Starter includes the first two, Growth and Professional include three. Professional retains advanced finance and governance modules.
No deployment is performed by this change. Verify credentials, database availability, billing webhooks and production configuration before launch.
